# sed 사용
sed 는 Stream Editor 터미널에서 사용할 수 있는 유용한 툴

sed 가 특정 문자열을 찾아서 바꿀 수 있다.  

## i
-i 옵션  in-place 출력 없이 찾아 바꾸기  
-i 이후 `` 안에 찾을 내용을 적어준다.   

커맨드의 구조는 / 로 구분된다.  
`s/serch/replace/g`  

예) sed -i 's/192\.168\.0\.100/192\.168\.0\.111/g' ~/myfile

myfile
``
192.168.0.110
192.168.0.120
192.168.1.121
'``
첫 번째줄인 192.168.0.110 이 192.168.0.111 로 변경된다. 


## E
-E 옵션, regular expression 사용할 때   
캡쳐 그룹으로 만들어서 원하는 패턴을 찾는다.  
위에서는 ip 만 찾았는데 ip 이후에 나오는 문자열을 찾고 싶다면  `[[:space:]]+` 를 사용한다.   

```
sed -E 's/^(127\.0\.1\.1[[:space:]]+).*/\1NEW_NAME_HERE/' 
```
^ 는 () 그룹에서 ip 로 시작하는 것만 찾는다.  
() 는 그룹으로 묶음, .* (닷, asterisk) 은 라인 끝까지 모든 것   
그래서 자세히 보면 /127.0.1.1스페이스모두/   <----- 여기가 search 파트  

**\1** 은 first 캡쳐된 그룹 이후에 위치하게 한다.  
/\1NEW_NAME_HERE/   <----- replace 파트


## cat 과 파이프  
sed 에서 직접 사용하기 어려운 경우 (퍼미션 등,, docker 환경 등.. )  

cat 으로 읽어서  
**|** 를 사용하면 그 결과를 넘겨줘서 받아서 사용할 수 있게 된다.  
이후 **>** 리다이렉트를 통해서 파일을 만들고 

필요한 경우에 temp로 파일을 만들어서 다시 덮어 씌운다.

사용할 일이 많이 없겠으나, 유용하다

```
sudo cat /etc/hosts | sed 's/127\.0\.1\.1/NEW_VALUE_HERE/g' > /tmp/hosts.tmp && sudo cp /tmp/hosts.tmp /etc/hosts
```
마지막으로 템프로 만들어진 파일을 다시 카피해서 사용
