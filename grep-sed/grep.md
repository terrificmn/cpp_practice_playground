# grep 사용
```
grep -E "127\.0\.1\.1[[:space:]]+원하는문자열" filename.txt
```
-E 옵션은 regex 를 사용할 수 있게 해준다.  

> . 앞에서는 \ 이스케이프를 해줌  
이를 c++에서 system 등으로 사용할 경우에는 \ 를 이스케이프 해줘야 한다. 예) 127\\.0\\.1\\.1  (2번 이스케이프 되는셈)

`[[:space:]]` 유용하게 사용할 수 있는 스페이스 찾기  
+ 정규식까지 더해서 space 을 1이상 찾는다. 그래서 탭키도 적용된다.   


`127.0.1.1     myname` 이런 문자열을 찾을 때 사용한다.
